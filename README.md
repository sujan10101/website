# Sujan Khadka - Personal Site

Simple TypeScript-powered landing page for sujankhadka.com.

## Run locally
1) Install Node.js 18+ and npm.  
2) Install deps: `npm install`  
3) Build TypeScript: `npm run build`  
4) Serve locally: `npm run serve` and open http://localhost:8080

During editing, use `npm run watch` to recompile on save.

## Deploy
Upload the `public` folder (including the generated `public/js` files) to your host.
# Sujan Khadka - Personal Website

A simple, clean personal website built with Angular.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open your browser and navigate to `http://localhost:4200`

### Build for Production

To build the project for production:

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.

## Deployment

After building, you can deploy the contents of the `dist/sujankhadka-website` folder to your web hosting service for sujankhadka.com.
